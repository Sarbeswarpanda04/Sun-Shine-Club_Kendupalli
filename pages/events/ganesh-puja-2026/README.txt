# Sun Shine Club — Ganesh Puja 2026 Status / Newspaper Page

## Folder structure

Place this page inside your existing event folder:

ganesh-puja-2026/
├── index.html
├── style.css
├── script.js
└── assets/
    └── events/
        └── ganesh-puja-2026/
            ├── hero.jpg
            ├── photo-01.jpg
            ├── photo-02.jpg
            ├── photo-03.jpg
            ├── photo-04.jpg
            ├── photo-05.jpg
            ├── photo-06.jpg
            └── photo-07.jpg

The code uses placeholder image filenames so you can simply replace the JPG files without editing the layout.

## Editable areas

1. `storyData` in script.js:
   - Story image
   - English title/text
   - Odia title/text

2. Prize cards in index.html:
   - First / Second / Third prize
   - Winner name
   - Prize details

3. Competition description:
   - Replace the generic competition paragraph with the exact competition categories.

## Features

- WhatsApp Status-style vertical visual story
- Auto-changing story with progress bars
- Swipe left/right on mobile
- Previous/next buttons
- Story thumbnail navigation
- Newspaper/editorial event article
- English ↔ Odia toggle with localStorage
- Mobile responsive navigation
- SEO title, description, keywords, canonical and Open Graph metadata
- Native share
- WhatsApp share
- Copy link
- Share modal with current image preview
- Save/open current story image
- Missing-image fallback
